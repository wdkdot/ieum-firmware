# 전력 운용 계획

## 목표

- 배터리: 3,000 mAh
- 최소 목표: 약 1주
- 기대 목표: 약 2-3주
- 실제 수명은 LoRa 수신 상태, 송신 빈도, BLE, GNSS 수신 환경과 E-ink 갱신 빈도에 크게 좌우된다.

이 문서는 아직 검증 전 운용 계획이다. 데이터시트의 최소·대표값만 합산한 수치는 실제 Meshtastic 배터리 수명을 보장하지 않는다.

## 부하별 정책

| 부하 | 운용 정책 | 절전 핵심 |
|---|---|---|
| RAK4630 | 상시 Meshtastic | 무선 역할과 sleep 비율이 지배적 |
| AHT20-F | 1분 간격 | 측정 후 대기 |
| BMP388_TOKMAS | 1분 간격 | Forced mode 후 sleep |
| MMA8652FC | 기본 6.25 Hz | Low Power, 필요 시 12.5 Hz 비교 |
| GNSS | 30분 간격 | fix 후 주 전원 차단 |
| E-ink | 이벤트 기반 | 갱신 후 전원 차단 |
| LED | 짧은 펄스 | 낮은 duty와 PWM 밝기 |

## GNSS 절전

가속도계가 정지 상태를 감지하면 GNSS 측정을 생략한다.

- 기본: 24시간 동안 30분마다 측정
- 절전: 수면 7시간과 정지 3시간을 합쳐 하루 약 10시간 동안 측정 생략

실제 절감량은 GNSS가 fix를 얻는 데 걸리는 시간과 켜져 있을 때의 전류가 결정한다. GNSS on-time, TTFF, 성공·실패 횟수, 일일 총 활성 시간과 VBAT 백업 유지 전류를 로그로 수집한다.

## 측정 방법

1. 완성 보드의 배터리 입력에 전력 분석기를 연결한다.
2. 부팅, idle, LoRa RX, LoRa TX, BLE 연결, 센서 측정, GNSS fix, E-ink 갱신을 각각 측정한다.
3. 순간 전류와 시간 적분 전하량을 함께 기록한다.
4. 실제 Meshtastic 설정으로 24시간 이상 장기 측정한다.
5. 평균전류를 구한 뒤 배터리 유효 용량과 변환 손실을 반영한다.

`예상 사용시간[h] = 배터리 유효용량[mAh] / 평균전류[mA]`

배터리 정격 3,000 mAh를 전부 사용할 수 있다고 가정하지 않는다. 저온, 노화, 보호회로 차단전압, DC/DC 효율과 고전류 펄스를 고려한다.

## 최적화 우선순위

1. LoRa 수신과 Meshtastic 역할별 평균전류 확인
2. GNSS 일일 총 활성 시간 단축
3. BLE 연결·광고 정책 확인
4. E-ink 및 GNSS 전원 차단 시 역급전 제거
5. LED duty 감소
6. 센서 ODR와 폴링 주기 미세 조정
