# 센서

모든 센서는 메인 MCU와 I²C로 통신한다. 실제 I²C 주소 선택 상태와 GPIO 연결은 회로도 및 추후 핀맵 문서에서 확정한다.

## AHT20-F 온습도 센서

- 기능: 온도 및 상대습도 측정
- 기반 부품: ASAIR AHT20
- 인터페이스: I²C
- 일반 AHT20 주소: 0x38
- 일반 AHT20 패키지: 3×3 mm LGA
- 대표 정확도: 습도 ±2 %RH, 온도 ±0.3 °C
- Ieum 측정 계획: 약 1분 간격

AHT20-F는 센서 개구부에 보호 필터가 적용된 변형이다. 일반 AHT20의 디지털 동작은 제조사 데이터시트를 따르되, F 변형의 필터 재질과 환경 보호 등급은 공급사 자료가 추가로 필요하다.

펌웨어는 측정을 시작한 뒤 busy 상태를 확인하고, 20비트 습도 원시값과 20비트 온도 원시값을 데이터시트의 변환식으로 계산해야 한다. 전원 투입 직후 초기화·보정 상태 확인 절차가 필요하다.

## BMP388_TOKMAS 기압 센서

- 기반 센서: Bosch Sensortec BMP388
- 기능: 절대기압 및 내부 온도 측정, 상대 고도 계산
- 인터페이스: I²C 또는 SPI
- Ieum 사용 방식: I²C
- BMP388 I²C 주소 후보: 0x76 또는 0x77
- CHIP_ID: 0x50
- 압력 범위: 300-1,250 hPa
- 출력: 보정 계수를 적용하는 24비트 압력·온도 데이터
- Ieum 측정 계획: 약 1분 간격

TOKMAS는 BMP388의 압력 포트 위에 보호 필터가 적용된 공급 형태다. 필터는 외부 공기의 기압 전달을 허용하면서 먼지와 이물질의 직접 유입을 줄이는 목적이다. 정확한 TOKMAS suffix와 필터 사양은 구매처 문서로 별도 보존해야 한다.

Ieum에서는 1분마다 한 번 측정하므로 계속 측정하는 Normal mode보다 Forced mode로 단발 측정하고 다시 Sleep mode로 돌아가는 방식이 적합하다. 실제 오버샘플링과 IIR 필터 설정은 응답 속도, 노이즈와 소비전력을 실물에서 비교해 결정한다.

주의:

- 압력·온도 보상 계산에는 NVM 보정 계수가 필요하다.
- 제조사 공식 BMP3 센서 API를 참고하거나 검증된 기존 드라이버를 우선 사용한다.
- 센서 포트에 직접 바람이 닿거나 케이스 내부 압력이 지연되면 고도값이 흔들릴 수 있다.

## MMA8652FC 가속도 센서

- 제조사: NXP/Freescale
- 기능: 3축 가속도, 움직임, 자유낙하, 펄스, transient, 방향 감지
- 해상도: 12비트
- 측정 범위: ±2 g, ±4 g, ±8 g
- 인터페이스: I²C
- I²C 주소: 0x1D
- WHO_AM_I: 레지스터 0x0D, 값 0x4A
- ODR 범위: 1.56-800 Hz
- FIFO: 32 sample
- 패키지: DFN-10, 2×2×1 mm
- 공급 전압: 1.95-3.6 V
- 디지털 인터페이스 전압: 1.62-3.6 V

PCB는 원래 MMA8653FC를 기준으로 설계했으나, MMA8652FC를 드롭인 대체 부품으로 실장할 계획이다. 두 부품은 동일 계열·패키지지만 MMA8652FC는 10비트 대신 12비트 출력, 32 sample FIFO, 더 다양한 motion detection 채널, 구성 가능한 orientation hysteresis와 high-pass filtered data를 제공한다.

### Ieum 운용 계획

- Low Power 모드
- 기본 ODR: 6.25 Hz
- 반응성이 부족하면 12.5 Hz를 비교 검토
- 초기 motion threshold: 1.25 g, debounce 320 ms; 실물 측정 후 조정
- INT1을 P0.09에 직결하고 push-pull active high, latched interrupt로 사용
- MCU 입력은 no-pull, rising edge로 설정
- 정지·움직임 상태를 판단하여 GNSS 측정을 생략하거나 재개
- 필요하면 방향, 충격 또는 탭 이벤트를 사용자 인터페이스에 활용

하나의 인터럽트 선에 여러 이벤트를 라우팅할 수 있으므로, MCU는 인터럽트 발생 후 `INT_SOURCE`와 `FF_MT_SRC`를 읽어 원인을 판별하고 latch를 해제한다.

### 호환성 주의

MMA8652FC와 MMA8653FC의 물리적 드롭인 호환만으로 펌웨어까지 완전히 동일하다고 가정하면 안 된다. WHO_AM_I, 해상도, FIFO 및 추가 기능 차이를 반영해야 한다. 기존 Meshtastic 드라이버가 MMA8653FC만 가정한다면 MMA8652FC ID와 12비트 데이터 처리를 추가한다.

## 센서 공통 운용

- AHT20-F와 BMP388_TOKMAS는 약 1분 간격으로 측정한다.
- 센서를 동시에 깨울 필요는 없으며 전류 피크와 처리 시간을 분산할 수 있다.
- I²C 오류 시 무한 대기하지 않고 timeout과 재초기화 횟수를 둔다.
- 한 센서의 실패가 Meshtastic 통신이나 UI 전체를 막지 않게 한다.
- 측정값과 센서 상태를 Meshtastic Telemetry 구조에 연결한다.
