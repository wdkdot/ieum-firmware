# USB, 보호 회로 및 디버깅

## USB-C

USB-C 단자는 충전과 nRF52840 USB 데이터 통신에 사용한다.

- CC1: 5.1 kΩ Rd
- CC2: 5.1 kΩ Rd
- USB 역할: 기본적으로 USB 2.0 device / sink
- D+·D−: RAK4630 USB로 연결
- 차동선 길이 차이: 약 1 mm
- 연속된 GND plane을 리턴 경로로 사용

별도의 22 Ω 직렬 저항은 넣지 않았으며, 설계 당시 RAK4630 모듈 내부 구성을 전제로 했다. 실제 모듈 회로와 USB 신호 품질은 bring-up 시 다시 확인한다.

## 보호 부품

| 대상 | 부품 | 역할 |
|---|---|---|
| D+·D− | H5VU25UC | 저용량 USB 데이터 라인 ESD 보호 |
| VBUS | H5VH16U | USB 5 V 입력 ESD 및 과도전압 보호 |

이 두 부품은 서로 바꾸어 기록하지 않는다. H5VU25UC가 데이터선용이고 H5VH16U가 VBUS용이다. 정확한 정전용량, 동작전압, 클램프 특성은 공급사 데이터시트를 저장한 뒤 추가한다.

## SWD 및 리셋

- 2×4, 2.54 mm SWD 헤더
- SWDIO, SWDCLK, RESET, 3V3 기준 전압, GND
- 리셋 택트 스위치

정확한 헤더 배열은 핀맵 문서와 PCB 실크를 기준으로 작성한다. 디버거 연결 전 3V3와 GND 위치를 멀티미터로 확인한다.

## 테스트 포인트

I²C SDA/SCL 테스트 포인트는 디버그 커넥터라기보다 조립 후 쇼트와 신호 존재 여부를 확인하기 위한 측정 지점이다. 다른 전원 및 신호 테스트 포인트는 PCB 레이아웃에서 추가 확인한다.
