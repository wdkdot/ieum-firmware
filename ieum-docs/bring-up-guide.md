# 초기 구동 및 검사 절차

이 절차는 첫 PCB를 조립한 뒤 전원, 통신, 센서와 주변장치를 단계적으로 검증하기 위한 초안이다.

## 1. 육안 검사

- IC 방향과 1번 핀 확인
- USB-C, FPC, RF 단자 납땜 확인
- MMA8652FC DFN 패드 브리지 확인
- E-ink 쇼트키 다이오드 방향 확인
- BQ25628E 주변 인덕터·커패시터 누락 확인
- 안테나 단자의 center와 GND 패드 확인

## 2. 무전원 검사

- VBAT-GND, VBUS-GND, SYS-GND, 3V3_MAIN-GND 저항
- SDA-SCL 및 각 신호의 GND 단락
- 인접 DFN 핀 브리지

저항값 하나만으로 합격을 단정하지 말고 다른 보드 5대 사이의 상대 비교도 사용한다.

## 3. 제한 전류 전원 인가

1. 배터리를 연결하지 않고 USB 입력에 전류 제한을 건다.
2. 비정상 발열과 전류 제한 진입 여부를 확인한다.
3. VBUS, SYS, 3V3_MAIN을 측정한다.
4. EN 스위치가 3V3_MAIN을 제어하는지 확인한다.
5. 배터리 연결 후 충전 전압과 전류 방향을 확인한다.

## 4. MCU 복구 경로

- SWD 기준전압과 GND 확인
- 디버거 연결 및 nRF52840 식별
- 플래시 erase·테스트 펌웨어 기록
- RESET 버튼과 USB serial 확인

## 5. I²C 스캔과 식별

| 부품          | 예상 주소/식별               | 검사                      |
| ------------- | ---------------------------- | ------------------------- |
| AHT20-F       | 0x38                         | 상태 읽기와 단발 측정     |
| BMP388_TOKMAS | 0x76 또는 0x77, CHIP_ID 0x50 | 주소 선택 상태 확인       |
| MMA8652FC     | 0x1D, WHO_AM_I 0x0D = 0x4A   | 12비트 XYZ 읽기           |
| BQ25628E      | 데이터시트 주소              | part/status 레지스터 확인 |

주소가 예상과 다르면 펌웨어를 먼저 고치지 말고 회로도의 주소 선택 핀과 납땜을 확인한다.

## 6. 센서 기능 검사

- AHT20-F: 손으로 감싸 온도·습도 변화 확인
- BMP388: 기압값과 온도값 확인
- MMA8652FC: 각 축을 위아래로 두어 약 ±1 g 방향 변화 확인
- MMA8652FC: INT1/P0.09의 평상시 LOW, 이벤트 HIGH, source read 후 LOW 복귀 확인
- MMA8652FC: FIFO 시험
- 센서 하나를 응답 불능으로 만들어 timeout과 오류 복구 확인

## 7. GNSS

- 주 전원과 VBAT를 각각 측정
- UART baud rate 및 NMEA 출력 확인
- 야외에서 첫 fix와 TTFF 측정
- 전원 차단 후 재가동 TTFF 비교
- 액티브 안테나 바이어스 전압 확인

## 8. E-ink

- 로드 스위치 출력 확인
- RESET과 BUSY 관찰
- 전체 흰색, 전체 검정색 및 흑백 패턴 표시
- 네 가장자리와 마지막 행·열이 보이는 패턴으로 184×360 방향과 0°/180° 회전 확인
- 전체 갱신과 빠른 갱신 시간 측정
- 일반 화면 `F7/DC/01`과 메뉴 `F4/1C/01`에서 BUSY 시간 비교
- 메뉴 진입 전체 갱신 뒤 연속 버튼 입력이 reset 없이 부분 갱신되는지 확인
- 메뉴 종료·timeout·shutdown 뒤 deep sleep, GPIO high-Z와 EINK_EN LOW 복귀 확인
- 부분 갱신을 연속 반복해 잔상 누적 시점과 전체 갱신 복구 확인
- BUSY를 의도적으로 active 상태로 만들어 timeout 뒤 EINK_EN LOW와 LoRa/BLE/USB 생존 확인
- deep sleep 후 로드 스위치 차단
- 전원 차단 상태에서 화면 유지, 각 SPI·제어 핀 전압과 역급전 전류 확인

## 9. LoRa 및 BLE

- 안테나를 연결한 뒤 송신 시험
- Meshtastic 메시지 송수신과 KR920 설정 확인
- RSSI/SNR 비교
- BLE 페어링과 설정
- LoRa TX 중 전원 레일 강하와 리셋 여부 확인

## 10. 완료 기록

보드 번호, 수정 내역, 각 전원 레일, idle 전류, 센서 주소·식별값, GNSS TTFF, E-ink 갱신 시간, LoRa/BLE 결과와 알려진 결함을 기록한다.
